MeetLedger データExport（データの書き出し）ガイド
====================================================

MeetLedger に保存したデータは、いつでも一般的な形式で書き出せます。
特定のAIサービスや MeetLedger 自体に閉じ込められないよう（ロックインしないよう）設計しています。

※ 文中の画面上のボタン名・メニュー名は、Web 画面の版によって表記が異なる場合があります。
  同じ操作は API でも行えます（9章）。


1. 書き出せるもの
----------------------------------------------------

  対象                    形式                         用途の例
  ----------------------  ---------------------------  ------------------------------------------
  会議ごとの記録          Markdown (.md)               社内Wiki・Notion・GitHub などへの貼り付け
                          HTML（印刷用）→ PDF          お客様・上長への共有、保管用PDF
                          JSON (.json)                 他システムへの連携
  文字起こし              テキスト (.txt)              そのまま読む・検索する
                          字幕 SRT (.srt) / VTT (.vtt)  動画編集ソフト・動画プレイヤーの字幕
  決定事項（Decision）    CSV / JSON                   Excel・スプレッドシートで一覧管理
  アクション（ToDo）      CSV                          タスク管理ツールへの取り込み
  約束（Commitment）      CSV                          お客様との約束の棚卸し
  プロジェクトの会議まとめ Markdown / HTML（印刷用）    プロジェクトの議事録集（Meeting Book）
  Workspace 全データ      JSON（音声ファイルの同梱も可）  移行・長期保管・別の MeetLedger への取り込み


2. 書き出しに必ず入る情報
----------------------------------------------------

  会議の書き出し（Markdown / HTML / テキスト / JSON / VTT）には次の情報が入ります。

    - タイトル
    - 日時（あなたのタイムゾーンで表示）
    - 参加者
    - 文字起こしの版（何回目の文字起こしか、端末内処理かクラウド処理か）
    - 生成日時（書き出した日時）

  AIが作った内容には「AI生成」、まだ人が確認していないAIの抽出結果には「候補（未確認）」
  というラベルが付きます。確定情報と区別してお使いください。


3. 会議を PDF にする方法
----------------------------------------------------

  1) 会議画面の「書き出し」から「HTML（印刷用）」を開きます。
  2) ブラウザの印刷（Windows: Ctrl+P / Mac: ⌘+P）を開きます。
  3) 送信先（プリンター）で「PDFとして保存」を選んで保存します。

  ※ PDF はブラウザの印刷機能で作成します。A4 に収まるよう、見出しや表が
    ページの途中で切れにくいレイアウトにしています。


4. CSV について
----------------------------------------------------

  - 文字コードは UTF-8（BOM付き）です。Excel でそのまま開いても日本語が文字化けしません。
  - 「=」「+」「-」「@」で始まる文字は、表計算ソフトで数式として実行されないよう、
    先頭に「'」（アポストロフィ）を付けて書き出します（CSVインジェクション対策）。
  - 決定事項の CSV には「変更の履歴（supersede chain）」の列があります。
    ある決定が後の会議で変更された場合、古い決定と新しい決定が同じ chain_root_id で
    つながり、chain_position（1, 2, 3 …）で順番が分かります。
  - 標準では確定済みの項目だけを書き出します。未確認の候補も含めたい場合は
    「候補を含める」を選んでください（API では includeCandidates=1）。


5. 見える範囲だけが書き出されます
----------------------------------------------------

  - 書き出しは、あなたが閲覧できる会議・項目だけが対象です。
  - 「非公開（自分のみ）」の会議は作成者本人しか書き出せません。管理者でも他人の
    非公開会議は書き出せません。


6. Workspace 全データの書き出し（管理者のみ）
----------------------------------------------------

  1) 設定 → データ管理 → 「全データを書き出す」を押します（音声を含めるか選べます）。
  2) 準備ができるとダウンロードボタンが表示されます。
  3) ダウンロードリンクは短時間（標準5分）だけ有効で、依頼した本人だけが使えます。
     期限が切れたら画面から再度リンクを表示してください。
  4) 書き出しファイルはサーバー上では暗号化して保管され、7日後に自動で削除されます。

  含まれるもの:
    会議、参加者、同意記録、メモ、文字起こし（全版）、話者、要約、決定事項・アクション・
    約束・質問、プロジェクト、定例、人物、テンプレート、削除記録・監査ログ（記録用）、
    （選択時）音声/動画ファイル

  含まれないもの（安全のため／再作成できるため）:
    パスワード、ログイン情報、APIトークン、招待リンク、カレンダー等の連携トークン、
    Webhook の秘密鍵、検索用・AI用の索引（取り込み時に自動で作り直します）、通知

  ユーザー情報は「ID・名前・メールアドレス」だけが入ります。

  ※ ダウンロードしたファイルには会議の内容がすべて含まれます。社外に送らない、
    不要になったら削除するなど、大切に扱ってください。


7. 全データの取り込み（インポート）
----------------------------------------------------

  書き出した JSON は、別の MeetLedger の「空の Workspace」に取り込めます（管理者のみ）。

  - すべての ID は新しく振り直されますが、つながり（決定の変更履歴、アクションと決定、
    約束と会議、文字起こしと話者など）はそのまま再現されます。
  - 取り込み先のメンバーとメールアドレスが一致するユーザーは、そのユーザーとして
    取り込まれます。一致しない場合は、作成者などは取り込みを行った人になり、
    「この人物はこのユーザー」という結び付きは外れます（後でそのユーザーを招待すると、
    メールアドレスで人物と自動的に結び付きます）。
  - クラウド文字起こし・クラウドAIの許可設定は取り込みません。必要なら取り込み先で
    改めて有効にしてください（データが意図せず外部に送られないようにするため）。
  - 取り込み後、検索とAI検索の索引は自動で作り直されます。
  - 既にデータがある Workspace には取り込めません（誤って混ざるのを防ぐため）。


8. 音声・文字起こしファイルの取り込み
----------------------------------------------------

  会議ごとに、音声/動画ファイル、または文字起こしファイル（SRT / VTT / テキスト / JSON）
  を取り込めます。会議画面の「アップロード」「文字起こしを取り込む」から行ってください。


9. API で書き出す場合（開発者向け）
----------------------------------------------------

  GET  /api/w/{workspaceId}/meetings/{meetingId}/export?format=md|html|txt|srt|vtt|json
  GET  /api/w/{workspaceId}/decisions/export?format=csv|json
  GET  /api/w/{workspaceId}/actions/export?format=csv
  GET  /api/w/{workspaceId}/commitments/export?format=csv
  GET  /api/w/{workspaceId}/projects/{projectId}/book?format=md|html
  POST /api/w/{workspaceId}/export/full        → { jobId }
  GET  /api/w/{workspaceId}/export/full/{jobId} → { status, url }
  POST /api/w/{workspaceId}/import/full        （書き出したJSONを送信）

  詳しくは docs/API_CONTRACT.md をご覧ください。
