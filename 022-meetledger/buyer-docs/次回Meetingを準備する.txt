MeetLedger 次回の会議（Meeting）を準備する
====================================================

前回までに決まったこと・残っているやること・約束・答えの出ていない問いを、次の会議の前に確認し、
議題（アジェンダ）にするための機能です。


1. 準備に使う 3 つの機能
----------------------------------------------------

  ブリーフ（Brief）      会議の前に読む「事前のまとめ」。前回からの未完了事項を集めて表示します。
  アジェンダ（Agenda）   議題の一覧。前回からの持ち越しを「候補」として追加できます。
  定例（Series）         毎週の定例などをまとめ、次回の会議を前回の情報を引き継いで作ります。

  どれも「確定した記録」だけを使います。未確認の候補や却下した項目は表示されません。
  また、見る人が閲覧できない会議（他人の「自分だけ（Private）」の会議など）の内容は表示されません。


2. ブリーフ（Brief）を見る
----------------------------------------------------

  会議を開くと、予定の会議では最初に「ブリーフ（Brief）」タブが表示されます。

  表示される内容（ある場合のみ）
    参加者                    名前・会社・役職、主催者
    前回のMeeting            同じ定例 → 同じ参加者 → 同じプロジェクトの順に、直近の会議を探します
                              （どれでつながったかがラベルで表示されます）
    未完了のやること          期限順。期限を過ぎたものも分かります
    自分の未完了の約束 / 相手の未完了の約束 / そのほかの未完了の約束
    未解決の問い
    最近の決まったこと        現在有効な決定
    最近変更された決まったこと 以前の決定 → 新しい決定
    相手について              参加者（自分以外）について、人（People）に書かれたメモ
    アジェンダ案              テンプレートの定型の議題。「アジェンダを編集」でアジェンダタブへ移ります

  初めての相手の場合
    「初めてのMeetingです」と表示され、参加者の基本情報と定型の議題だけが出ます
    （情報が無いのに、無理に内容を作ることはしません）。

  ブリーフは「事実」だけを並べます。人の性格や意図を推測・評価する内容は表示しません。
  件数が多い場合は「ほか n 件」と表示され、一部が省略されます。


3. アジェンダ（Agenda）を作る
----------------------------------------------------

  会議の「アジェンダ（Agenda）」タブ
    1) 「前回からの持ち越しを提案」を押すと、前回の会議・定例の未完了のやること・約束・未解決の問いと、
       テンプレートの議題が「候補」のラベル付きで追加されます。何度押しても重複しません。
    2) 提案ごとに「承認」または「却下」を選びます。却下した項目は「却下した項目を表示」で見られます。
    3) 自分で議題を書く場合は、「項目を追加」の欄に入力して「追加」を押します。
    4) 会議中、話し終えた議題には、項目の左のチェックボックスでチェックを付けます。
    - 提案の横には出典（前回のやること / 前回の約束 / 未解決の問い / テンプレート など）が表示されます。


4. 定例（Series）を使う
----------------------------------------------------

  定例を作る
    1) 左のメニュー「定例（Series）」→「定例を追加」。
    2) 定例の名前、頻度（例: 毎週火曜 10:00。メモとして記録されます）、種類、テンプレート、
       プロジェクト、公開範囲などを入力して作成します。
       ※ 頻度の欄から会議が自動で作られることはありません。次回の会議は 3 の手順で作ります。
    3) 会議を作るとき（「新しいMeeting」）に「定例（Series）」でこの定例を選ぶと、定例にまとまります。

  次回の会議を作る
    1) 定例のページで「次回Meetingを作成」を押します。
    2) 開始日時（前回の 1 週間後が初期値）とタイトル（任意）を確認して作成します。
    3) 前回の参加者と公開範囲が引き継がれ、アジェンダの候補も自動で追加されます。
       前回の未完了のやること・約束・未解決の問いは、次回のブリーフに表示されます。

  定例のページには「定例の記憶（Series Memory）」として、有効な決定、未完了のやること・約束、
  未解決の問い、最近の変更、前回・次回の会議がまとまって表示されます。


5. 通知で思い出す
----------------------------------------------------

  - 会議前ブリーフ: 会議の開始の一定時間前（標準 60 分前）に、作成者と、MeetLedger のユーザーに
    結び付いた参加者（その会議を閲覧できる人）へ届きます。「通知」→「通知の設定」→
    「会議前ブリーフを送るタイミング（分前）」で変更できます（0 で送らない）。
  - 次回Meeting: 定例の会議が終わって次回がまだ登録されていないとき、作成者に届きます。
  - 静かな時間帯（標準 22:00〜8:00）には通知を送りません。静かな時間帯のせいで会議の開始に間に合わない
    会議前ブリーフは、送られずに取り消されます。


6. カレンダーから会議を作る（任意）
----------------------------------------------------

  Google カレンダー / Microsoft 365 / ICS（iCalendar）から予定を読み込み、選んだ予定を会議として
  取り込めます。カレンダーへ書き込むことはありません。設定方法は「Connector.txt」をご覧ください。


7. プロジェクトの記憶・トピックの記憶
----------------------------------------------------

  - プロジェクト（またはクライアント）のページの「プロジェクトの記憶（Project Memory）」で、
    そのプロジェクトの有効な決定・未完了の約束・やること・未解決の問い・最近の変更をまとめて見られます。
    「記録集をダウンロード」で会議の記録をまとめて書き出せます（「データExport.txt」）。
  - 左のメニュー「記憶（Memory）」でトピック（例: 料金プラン）を入力すると、そのトピックについて
    会議をまたいだ決定の流れと未完了の事柄を表示します。言葉の一致で探すため、言い換えや表記ゆれ
    （見積り / 見積もり など）は見つからないことがあります。


8. AI アシスタントから準備する（任意）
----------------------------------------------------

  ChatGPT / Codex などの MCP 対応ツールから、次回の会議の準備（前回の未完了事項の確認、次回の会議の作成）を
  行えます。会議の作成は、プレビューを確認してから実行する 2 段階です。
  現在、Codex などは API トークンで接続できますが、ChatGPT からの接続に必要な OAuth 認証は未対応です
  （「Connector.txt」6 章）。
