MeetLedger 録音と参加者への通知（同意）ガイド
====================================================

録音・文字起こしの前に、参加者へ伝えること、MeetLedger での記録の残し方、
録音できる音声の範囲（ブラウザ / スマートフォン / デスクトップアプリ）をまとめています。

ご注意
  MeetLedger は参加者への通知と、その記録をサポートします。ただし、録音・文字起こしに関する法令や
  社内規程への適合を保証するものではありません。録音してよいか、どう伝えるか、同意が必要かは、
  お客様の責任でご判断ください（法的助言ではありません）。参加者が録音を望まない場合は、録音しないでください。


1. 基本のルール
----------------------------------------------------

  - 秘密録音の機能はありません。参加者に知らせずに録音する使い方はできません。
  - 参加者へ伝えたことを MeetLedger に記録するまで、録音・録音ファイルのアップロードは始められません
    （画面だけでなく、サーバー側でも確認しています）。
  - 録音中は、画面に常に「録音中」と表示されます。
  - 参加者が録音を希望しない場合は「録音しない（メモのみで進める）」を選びます。その会議では録音・
    アップロードができなくなり、メモで記録を続けます。
  - MeetLedger が参加者へ通知メールなどを自動で送ることはありません。伝えるのはお客様自身です
    （下の文例をお使いください）。
  - 声から人物を特定する機能はありません。話者は「Speaker 1」などの匿名ラベルで、名前は人が設定します。


2. ブラウザで録音するときの手順
----------------------------------------------------

  1) 会議の「記録（Capture）」タブで「録音を開始」を押します。
  2) 「録音を始める前に（参加者への通知）」が開きます。次の内容が表示されるので、参加者全員に伝えます。
       録音           この端末のマイク音声を録音します（会議アプリの相手側音声・システム音声は含まれません）
       文字起こし     ローカル（このサーバー内）か、クラウドか
       音声の保存期間 例: 処理が終わるまで
       AI処理         ローカルか、クラウドか、行わないか
       外部への送信先 例: なし（このサーバー内で処理）
  3) 「伝えた方法」を選びます（口頭で伝えた / カレンダーの説明欄に記載 / チャットで伝えた / メールで伝えた）。
  4) 「参加者全員に、録音・文字起こし・AI処理・保存期間を伝えました」にチェックを入れます。
     必要なら「メモ（任意）」に記録を残します（例: 冒頭で口頭確認、異議なし）。
  5) 「通知を記録して録音を開始」を押すと、録音が始まります。

  録音しない場合は、同じ画面で「録音しない（メモのみで進める）」を押します。

  録音ファイルをアップロードする場合も、「アップロードする前に（参加者への通知）」で、録音時に
  参加者全員へ伝えたことを確認してから「通知を記録してアップロード」を押します。


3. 通知の記録を確認する・追加する
----------------------------------------------------

  - 会議の「設定」タブ →「参加者への通知・同意」に、現在の状態と記録の一覧（種類・方法・日時）が表示されます。
  - 事前にカレンダーやメールで伝えた場合は、「通知を記録」から先に記録しておくこともできます。
  - 状態の表示: 録音なし / 通知前 / 参加者に通知済み / 同意を確認済み / 録音しない（希望あり）


4. 録音中の表示と操作（ブラウザ）
----------------------------------------------------

  - 赤い点と「録音中」、経過時間、入力レベルが表示され、ブラウザのタブ名も「● 録音中 — MeetLedger」になります。
  - 「一時停止」「再開」「停止してアップロード」「録音を破棄」が使えます。
  - 録音データは端末にも一時保存されるため、通信が切れても失われません。アップロードできなかった録音は
    「まだアップロードしていない録音」に表示され、あとから「アップロード」「ダウンロード」「削除」ができます。
  - 録音中は画面を開いたままにしてください（特に iPhone / iPad）。


5. 録音できる音声の範囲
----------------------------------------------------

  Web アプリ・PWA（パソコン）
    - 録音できるのは、その端末のマイク音声だけです。
    - Zoom・Teams・Google Meet などのアプリの相手側の音声や、パソコンのシステム音声は録音できません。
    - Chrome / Edge では、「ブラウザのタブ音声も含める（Chrome / Edge）」をオンにして、画面共有で会議の
      タブを選び「タブの音声も共有」をオンにすると、そのタブの音声も録音できる場合があります
      （ブラウザ・OS により異なり、保証されません）。共有中はブラウザに表示されます。

  スマートフォン（iPhone / iPad / Android）
    - マイクのみです。iPhone / iPad では、画面を消したりほかのアプリに切り替えると録音が止まります。
      Android でも、バックグラウンドに移ると止まる場合があります（「スマホ-PWA.txt」）。

  デスクトップアプリ（MeetLedger Desktop、Windows / macOS）
    - マイク（左チャンネル＝あなた）と、システム音声（右チャンネル＝相手）を分けて録音します。
    - Windows: パソコンの既定の出力先に流れるすべての音（通知音や動画の音なども含む）が録音されます。
      ヘッドホンの使用をおすすめします。
    - macOS: 14.2 以降で、初回に「システムオーディオ収録」の許可が求められます。取得できなかった場合は
      マイクのみで録音を続けます。
    - Windows / macOS の実機でのシステム音声の録音は、開発環境では確認できていません（未検証）。
      導入前に、お客様のパソコンと会議ツールで必ず試してください。
    - 画面の内容は記録しません。


6. デスクトップアプリでの手順
----------------------------------------------------

  初回の設定
    1) 起動すると設定画面が開きます。「MeetLedger サーバーの URL」を入力し、「接続テスト」→「保存して開く」。
    2) 開いた Web アプリでログインします。
    3) パソコンの中で文字起こしをする場合は、設定画面の「文字起こしモデル（端末内）」でモデルを
       ダウンロードします（サイズとライセンスの確認ダイアログが出ます）。

  録音
    1) メニュー「ファイル」→「デスクトップ録音…」で録音ウィンドウを開きます。
    2) 「1 会議を選択」: ワークスペースと会議を選びます（「新規作成」もできます）。
    3) 「2 参加者への通知・同意」: 「参加者全員に、この会議を録音・文字起こしすることを伝えました」に
       チェックし、方法と状態（通知した / 同意を得た）を選んで「記録する」。
    4) 「3 処理方法」:
         この端末で文字起こし（音声は送信しない／テキストのみ送信）  ※必要なら「音声もアップロード」
         音声をサーバーへアップロード（サーバー側で文字起こし）
         「システム音声（相手の声）も録音する」
       を選び、「録音を準備（会議を開始）」。
    5) 「4 録音」: 「● 録音開始」で録音、「■ 停止」で終了します。
    6) 「5 結果の送信」: 「この端末で文字起こし」→ 結果を確認 →「文字起こし結果を送信」、または
       「音声をアップロード」。最後に「完了（端末のファイルを削除）」。

  録音中の表示
    - すべてのウィンドウのタイトルに「● 録音中」が付き、録音ウィンドウは最前面に表示されて最小化できません。
    - トレイのアイコンが変わり、Windows ではタスクバー、macOS では Dock にも表示されます。
    - 録音中にウィンドウを閉じたりアプリを終了しようとすると、確認が表示されます。


7. 音声の保存期間
----------------------------------------------------

  会議ごとに「音声の保存期間」を選べます（初期値は管理者が「設定」→「プライバシー」で決めます）。
    保存しない         処理中も再生できず、処理が終わると削除
    処理が終わるまで   文字起こしが成功したら削除（標準）
    7日間 / 30日間 / 日数を指定   期間中は再生でき、期限を過ぎると自動で削除
  音声を削除しても、文字起こしは残ります。機密（Confidential）の会議は「保存しない」か「処理が終わるまで」だけです。
  会議の「設定」タブ →「データの削除」から、音声だけを手動で削除することもできます。


8. 参加者への通知文例（コピーしてお使いください）
----------------------------------------------------

  事前（カレンダー招待・メール）
    本会議は議事録作成と決定事項・宿題の管理のため、MeetLedger で録音・文字起こしを行います。
    音声は文字起こし後に削除し（保存期間: ○○）、文字起こしと要約は社内の関係者のみが閲覧します。
    [クラウドを使う場合: 文字起こし/要約のため ○○社（所在国: ○○）のサービスへ送信します。]
    録音を希望されない場合は事前にお知らせください。録音なしで進行します。

  会議の冒頭（口頭 / チャット）
    これから議事録作成のため録音と文字起こしを開始します。録音を希望されない方はお知らせください。

  English
    This meeting will be recorded and transcribed with MeetLedger to keep track of decisions and action items.
    Audio is deleted after transcription. Let us know if you prefer not to be recorded — we will continue
    without recording.

  ※ 文例は参考です。お客様の利用目的・保存期間・送信先に合わせて書き換えてください。
  ※ 法令に関する調査メモ（個人情報保護法、外国にある第三者への提供、海外の録音同意法など。法的助言ではありません）は
    docs/PRIVACY_CONSENT.md 5 章にあります。


9. 導入企業でやっておくこと
----------------------------------------------------

  1) 利用目的と、録音・文字起こし・AI 処理・保存期間・委託先をプライバシーポリシー等に記載する。
  2) クラウド処理を使う前に、委託先との契約（データの学習利用の有無、保存期間、地域）を確認する。
  3) 音声・文字起こしの保存期間の初期値を決める（「設定」→「プライバシー」）。
  4) 録音を断られた場合の進め方（メモで記録する）を、社内で共有しておく。
