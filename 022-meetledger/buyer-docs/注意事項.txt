MeetLedger ご利用上の注意事項
====================================================
対象バージョン: MeetLedger 1.0（2026-10-02 時点）

MeetLedger を安全に、正しくお使いいただくための注意事項です。導入前に必ずお読みください。


1. 法的な位置づけ
----------------------------------------------------

  - MeetLedger は法的助言を提供しません。本製品および付属文書の記載は、法的助言ではありません。
  - MeetLedger は、参加者への通知・同意の記録、保存期間の設定、外部送信の制限などを「支援」する機能を
    持ちますが、個人情報保護法、各国・各州の録音同意に関する法令、GDPR、労働関係の法令、業界の規制、
    社内規程などへの適合を保証するものではありません。
  - 録音してよいか、どのように通知・同意を得るか、どのデータをどこに送ってよいか、どのくらい保存するかは、
    お客様（導入する事業者）の責任で判断してください。必要に応じて、弁護士などの専門家にご相談ください。
  - 付属文書にある法令の情報（docs/PRIVACY_CONSENT.md など）は、2026-10-02 時点の調査メモです。
    一部は検索結果の要約にもとづくもので、原文の確認が必要です。


2. AI の出力について
----------------------------------------------------

  - 文字起こし・要約・候補の抽出・AI への質問の回答は、誤ることがあります。必ず人が確認してください。
  - AI が見つけた決まったこと・やること・約束・問いは、人が承認するまで「候補」のままです。
    承認する前に、根拠の発言（「元の発言を開く」）を確認してください。
  - MeetLedger は、聞き取れなかった部分を推測で埋めず、根拠の無い担当者・期限を作らないように設計して
    いますが、それでも誤りがなくなるわけではありません。
  - 文字起こしの精度は、クリアな音声でも 1 文に 1 語程度の誤りがありました。実際の会議音声（雑音、
    話し声の重なり、専門用語）での精度は測定していません。重要な内容（金額・日付・固有名詞など）は、
    音声や参加者に必ず確認してください。
  - 「AI生成」のラベルが付いた内容（要約など）を、そのまま社外への正式な記録や契約の根拠として使わないでください。
  - AI の回答に「記録からは分かりません」と出た場合、記録に十分な根拠が無いことを意味します。


3. 禁止事項（してはいけない使い方）
----------------------------------------------------

  MeetLedger を、次の目的で使わないでください。

  - 秘密録音: 参加者に知らせずに録音・文字起こしをすること。録音を断った人がいるのに録音すること。
  - 盗聴: 電話や会話を、当事者の同意なく録音・傍受すること。
  - 面接・試験での不正: 面接・試験・商談などで、相手に隠して AI の回答や情報を表示させる、
    不正に有利になるよう使うこと。
  - 従業員の監視: 発言時間・発言回数・やることの完了状況などを、従業員の監視に使うこと。
  - 人事評価・人物評価: AI の出力や会議の記録をもとに、人事評価、採用候補者の人格・能力の評価、
    感情や心理の推定を行うこと。MeetLedger の「ふりかえり（Coach）」は事実の指標だけを表示するもので、
    人の評価に使うものではありません。
  - 医療・法律などの専門的な助言としての利用: AI の回答や要約を、医療・法律・税務などの専門家の判断の
    代わりにすること。
  - 無断の声の複製（Voice Clone）: 録音した音声を、本人の同意なく声の複製・合成に使うこと。
  - 声による本人特定: 録音から人物を特定・照合する目的で使うこと（MeetLedger にこの機能はありません）。
  - 迷惑メールなど: 会議の情報を使った、相手の同意のない大量の営業メールの送信。
  - そのほか、法令・公序良俗に反する使い方、他人の権利（プライバシー・著作権など）を侵害する使い方。


4. データの管理はお客様の責任です
----------------------------------------------------

  MeetLedger はお客様のサーバーで動くソフトウェアです。データの保管・保護はお客様が行います。

  暗号鍵（MASTER_KEY）
    - 音声ファイル・書き出しファイル・連携サービスの認証情報は、MASTER_KEY から作った鍵で暗号化しています。
    - MASTER_KEY を失うと、暗号化されたデータは二度と読めません。販売元も復元できません。
    - 生成したらすぐに、2 か所以上（パスワード管理ツールの共有金庫＋オフラインの保管など）に、2 人以上の
      担当者が取り出せるように保管してください。バックアップとは別の場所に保管してください。
    - 現在のバージョンには、MASTER_KEY を交換（再暗号化）する機能がありません。

  バックアップ
    - データベース・ファイル置き場・MASTER_KEY の 3 つがそろって、はじめて元に戻せます（「Backup-Restore.txt」）。
    - 毎日のバックアップ、暗号化した保管、サーバーとは別の場所への保管、定期的な復元の練習をおすすめします。
    - バックアップファイルのデータベース部分は暗号化されていません（文字起こしやメモがそのまま入っています）。
      バックアップファイル自体を暗号化して保管してください。
    - 削除したデータも、過去のバックアップには保管期間が終わるまで残ります。古いバックアップから戻すと、
      削除したデータが戻ります。

  そのほか
    - データベースの中の文字起こし・メモは暗号化されていません。ディスクの暗号化と、アクセスできる人の限定を
      行ってください。
    - サーバーの OS・ソフトウェアの更新、HTTPS の設定、アクセス権の管理、退職者のアカウント削除、
      API トークンの管理（不要になったら無効にする）を行ってください。
    - 書き出した（エクスポートした）ファイルは MeetLedger の管理外です。社外に送らない、不要になったら
      削除するなど、大切に扱ってください。
    - プライバシーポリシー等に、録音・文字起こし・AI 処理・保存期間（バックアップの保管期間を含む）・
      委託先を記載してください。
    - クラウド処理を有効にする場合は、委託先との契約（学習への利用、保存期間、処理する国・地域）を確認してください。


5. 既知の制限・未検証の事項
----------------------------------------------------

  「未検証」は、開発環境で実際の動作を確認できていないことを意味します。本番利用の前に、お客様の環境で
  必ず確認してください。

  録音・デスクトップアプリ
    - Windows / macOS の実機での、デスクトップアプリのシステム音声（相手側の音声）の録音は未検証です。
      macOS では、OS の版によって録音できない可能性（Electron の既知の不具合 #52738）や、画面収録の許可を
      求められる可能性があります。
    - Windows のインストーラー、コード署名、SmartScreen、macOS の署名・公証（notarization）は未検証です。
      署名のないビルドでは警告が表示されます。
    - Windows ではシステム音声に、会議アプリ以外の音（通知音・動画など）も含まれます。
    - Windows（ARM 版）では、パソコン内での文字起こしは使えません。
    - デスクトップアプリの自動更新、英語表示は未実装です。Linux 版は開発・検証用です。
    - Web アプリ・PWA はマイクの音声しか録音できません。iPhone / iPad では画面を消すと録音が止まります。

  文字起こし
    - 実際の会議音声での文字起こしの精度、日本語の会議での話者分離の精度は、測定していません。
    - ローカル文字起こしは「認識の確度」を返さないため、確度の低い箇所の表示はありません。
    - 録音の再生は先頭からのストリーミングで、長い音声の途中への移動はブラウザに依存します。
    - OpenAI の gpt-4o 系の文字起こしモデル（whisper-1、gpt-4o-transcribe、gpt-4o-mini-transcribe、
      gpt-4o-transcribe-diarize）は 2027-02-26 に提供終了と告知されています（2026-10-02 時点の調査）。
      後継モデルでの動作・話者分離は未確認です。
    - OpenAI への送信は 1 ファイル約 25MB までで、分割送信には対応していません。

  クラウドサービス・連携
    - クラウドの文字起こし（OpenAI / Deepgram）、AI（OpenAI / Anthropic / Ollama）、AI 検索用データ（OpenAI）は、
      実際の API への接続を確認していません（模擬応答によるテストのみ）。
    - Google / Microsoft カレンダー、Slack、HubSpot、Gmail、ChatGPT、Codex との実際の接続は未検証です。
    - ChatGPT からの接続に必要な OAuth 2.1 認証は未実装です（Codex などは API トークンで接続できます）。
    - 現在の画面から登録できる送信先は Slack（Incoming Webhook）・Webhook・HubSpot です。
    - メール送信（SMTP）の実際のメールサーバーでの動作は未検証です。

  検索・AI
    - 標準の AI 検索用データ（local-hash）は言葉の一致にもとづくもので、意味の近さでは探せません
      （例: 「価格」と「値段」）。
    - 自社サーバーの Ollama を AI 検索用データに選んでも、現在は local-hash で処理されます。
    - 標準の AI（ローカルのルール）は、指示語・言い換え・文をまたぐ内容を扱えず、取りこぼしや誤検出があります。
    - 記憶（Memory）・トピックの検索は言葉の一致で、表記ゆれ（見積り / 見積もり）は見つからないことがあります。

  動作環境・運用
    - 付属の Docker compose の構成は、開発環境に Docker が無かったため未検証です。
    - 自動テストはパソコンの Chromium でのみ実施しています。iPhone / Android の実機、Safari、Firefox での
      動作は未検証です（スマートフォン表示の確認は、パソコンのブラウザでの模擬（エミュレーション）にとどまります）。
    - 外部の専門家によるセキュリティ診断（ペネトレーションテスト）、依存パッケージの脆弱性監査、TLS 設定の確認は
      実施していません。
    - 静かな時間帯の計算は、夏時間の切り替え直後に最大 1 時間ずれることがあります。

  画面の制限（API では可能なもの）
    - 約束（Commitment）の手動追加、確定後のやることの担当者・期限の変更、決定の取り消しは、現在の画面では行えません。
    - サンプル Workspace の削除は、運用者によるデータベース操作が必要です。

  ライセンス
    - 話者分離のモデル（3D-Speaker CAM++）の商用利用ライセンスは未確認です。販売・商用利用の前に法務確認が必要です。
      文字起こしだけなら、このモデルは不要です。
    - Silero VAD のライセンス原文は再確認していません。
    - 文字起こしモデル SenseVoiceSmall は、出典の表示が必要です。サーバーでの文字起こしについては、Web 画面に
      表示する場所が現在ありません。社内向けの案内などで「THIRD_PARTY_NOTICES.txt」1 章の文言を表示してください
      （デスクトップアプリでは設定画面の「クレジット表記」に表示されます）。


6. お問い合わせの前に
----------------------------------------------------

  - 問題が起きたときは、まず「はじめに.txt」11 章と docs/OPERATIONS.md の監視の項目を確認してください。
  - サーバーのログには、会議の内容（文字起こし・メモ・AI の入出力）は記録されません。お問い合わせの際も、
    会議の内容を送る必要はありません。
