## 1. コスト構造の考え方
| 費目 | 何に比例するか | MeetLedgerでの既定 | 備考 |
|---|---|---|---|
| 文字起こし（Transcription） | 音声時間 | **Local（サーバ/PCのCPU、API費0）** | Cloud を使う場合は Workspace 管理者の opt-in + インストール側設定が必要。**最大のコスト要因** |
| AI（要約・抽出・Ask・文面調整） | Transcript 文字数・Ask 回数 | **local-rules（API費0）** | Cloud LLM は opt-in。AI OFF Meeting は 0 |
| Embedding | Transcript 文字数 | local-hash（0） | OpenAI 使用時もごく小額 |
| Storage（音声・動画） | 音声サイズ × 保存期間 | **Until processed（処理後削除）** | 30日保持・動画アップロードで増える |
| DB | 会議数・Transcript量・同時利用 | PostgreSQL 1台 | 小規模はマネージドの最小構成で足りる |
| Jobs（処理ワーカー） | 音声時間（Local ASR の CPU 時間） | アプリと同居 | Local ASR は実測 RTF ≈ 0.21（下記） |
| Email | 通知数 | outbox（送信しない） | SMTP/SES 利用時のみ |
| 帯域（egress） | 音声ダウンロード・エクスポート | 小 | AWS 東京 $0.114/GB [一次] |

### Local ASR の実測（2026-10-02、本開発環境）
- 環境: 4 vCPU Xeon（コンテナ）、sherpa-onnx-node 1.13.8、SenseVoice int8 + silero VAD。
- **RTF（処理時間/音声時間）: 文字起こしのみ ≈ 0.12、話者分離込み ≈ 0.21**（1時間の会議 ≈ 7〜13分のCPU処理）。
- 精度: 同梱のクリーン音声で日本語1語誤り・英語1語誤り程度。**実会議音声（雑音・重なり発話・専門用語）での CER/DER は未測定** → 販売前に自社テストセットで測定すること。

## 2. 読み方・注意
- 上表の月額は **API/送信系 + マネージドDB + 音声保存** の合計。**アプリサーバ（VM/コンテナ）、TLS 終端、バックアップ保管、監視、人件費は含まない**（利用先の環境で大きく変わるため）。
- Local-first（プラン A）は API 費が 0 の代わりに CPU 時間が必要。1000 時間/月なら RTF 0.21 で約 210 CPU 時間 → 4 vCPU 機で概ね 1 日 2〜3 時間の処理負荷。夜間や会議後の空き時間に処理するなら専用機 1 台で賄える規模。
- Cloud 文字起こしは「話者分離込み」で比較すること（Deepgram は話者分離が別料金）。**本バージョンが対応する Cloud 文字起こしは OpenAI と Deepgram のみ**。AssemblyAI / ElevenLabs は参考価格（未対応、Pro 候補）。
- **OpenAI の gpt-4o 系文字起こしモデルは 2027-02-26 提供終了予定**（後継 gpt-transcribe の話者分離対応は未確認）。MeetLedger はモデル名を `OPENAI_TRANSCRIBE_MODEL` で変更可能。
- 新しい Claude モデルのトークナイザは同じ日本語文で約 30% 多くのトークンを使う場合がある（research A）。上表は 1 token/文字の保守的な仮定。
- AI OFF / Confidential Meeting は AI 費・埋め込み費が 0。
- 動画アップロードを 30 日以上保持すると Storage 費が支配的になる（例: 1000 時間/月・動画720p・90日保持で約 $66/月）。音声のみ・Until processed を推奨。
- バックアップ: CLI `backup` の tar.gz を別ストレージに保管する場合、その容量 × 保持世代分の S3 費用が追加（S3 Standard 東京 $0.025/GB-月 [一次]）。

## 4. コストを抑える設定
1. 文字起こしは Local（既定）。Cloud は精度が必要な Meeting だけ `transcriptionMode=cloud`。
2. 音声保存は Until processed（既定）。再生が必要なら 7 日。
3. AI は local-rules（既定）または Haiku 級の小型モデル。Ask の回数が多い組織は Ask 単価（入力 6k tokens/回の仮定）を見直す。
4. 動画は音声のみ抽出してアップロード（Web録音は Opus 64kbps で約 29MB/時、Desktop録音は stereo 96kbps で約 43MB/時）。
